Installation

      

        

          
Marketplace (formerly HACS)

          
    
            
  1. Click the Home Assistant badge above, or open Marketplace in Home Assistant.
    2. 
            
  2. Open the menu (three dots) → Custom repositories.
    3. 
            
  3. Add https://github.com/firstof9/ha-appliance-status-card as a Dashboard / Lovelace repository.
    4. 
            
  4. Click Install and add custom:appliance-card via the Visual Editor.
    5. 
          

        

        

          
Manual

          
    
            
  1. Download appliance-card.js from the latest release.
    2. 
            
  2. Copy it to <config>/www/appliance-card.js.
    3. 
            
  3. Register /local/appliance-card.js as a JavaScript module under Settings → Dashboards → Resources.
    4.
